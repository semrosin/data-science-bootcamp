# Локальные эксперименты

Скрипты в этой папке нужны только для проверки гипотез на исторических данных.
Генерация `answer.csv` через `solution.py` их не запускает и не импортирует.

Из корня репозитория можно повторить оценку известных текстов запросов:

```powershell
python -m experiments.evaluate_known --dataset dataset
```
